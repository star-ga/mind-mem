## 3. Where mind-mem already leads (consolidated — do not touch)

- **Closed admission table + allow-list servability.** `enums.py:244-255` decides every ingest tier's initial status in one table; `SERVABLE = {ACTIVE}`; `_withhold_inadmissible` is an allow-list that refreshes stale cached statuses first. Mem0/Zep/Letta all write agent-extracted memory straight into the retrievable store; MINJA assumes that. Ours is closed by construction.
- **Admissibility applied to the retrieval *statistics* surface.** Per-leg admission before RRF (`hybrid_recall.py:905-914`) so withheld content cannot perturb a neighbour's rank; `blocks_fts` holds only admitted blocks because `bm25()` IDF/avg-doclen is corpus-wide (`sqlite_index.py:96-116`, with the measured leak). Nobody else treats fusion rank or corpus statistics as an information channel.
- **Replayable, attested recall.** One `scoring_instant` resolved at the boundary and threaded through every recency/calibration/temporal term; `RECALL_ATTEST_v2` per serve; a build gate (`test_every_serving_surface_attests.py`) that fails when a new content tool skips the record; recall-cache keys bound to the ledger head so invalidation is structural. A category the field does not have.
- **Honest degradation.** `VectorLegError`/`BM25LegError`, in-band `degraded` markers, `hybrid_single_list_degenerate`, `fusion_sources` per hit, the vector-inertness gauge that drops a chance-level vector arm rather than blending noise, `bm25_fallback` vs `hybrid_pgvector` labels on Postgres. Industry default is to serve BM25 and keep the word "hybrid".
