# Governed memory consumption of MIND-Lab discoveries

Status: proposed / review required / default OFF. No implementation or deployment is claimed.
Sources: https://arxiv.org/abs/2603.01092 ; https://github.com/alejandrohdez00/alien-space-of-science ; https://github.com/tiptreesystems/lacuna-research-mcp

MIND-Mem is the governed store of record, not an experiment engine or automatically authoritative research database. MIND-Lab owns research proposals and result generation; Naestro owns user-facing orchestration.

- [ ] Define opt-in provenance-linked storage of externally verified MIND-Lab experiment receipts, with bounded source/corpus/model revision identifiers.
- [ ] Keep speculative hypotheses, unverified Alien/Lacuna research leads and rankings separate from approved factual memory.
- [ ] Require propose → review → approve_apply for durable promotion; preserve contradiction/lifecycle/privacy/access checks and replayable evidence.
- [ ] Prefer existing hybrid retrieval, atomic fact indexing and graph associations; only evaluate new concept-composition features against measured incremental benefit.
- [ ] Validate revocation/correction, stale studies, conflicting evidence and source retraction without silent overwrites.

No external scorer can silently mutate memory or bypass approval.
