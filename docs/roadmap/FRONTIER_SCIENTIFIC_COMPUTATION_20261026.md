# Frontier Scientific Computation — roadmap proposal (2026-10-26)

**Status:** PROPOSED; not implemented or release-qualified.

## Repository responsibilities

Persistent derivation graphs, checkpoint indices, failed hypotheses, provenance deduplication, retrieval and reproducible replay.

## Cross-ecosystem acceptance

1. Preserve existing release blockers, compiler pins and repository ownership; do not divert active delivery.
2. Freeze small, independently known published symbolic tasks before implementation; scale difficulty only after verified success.
3. Require independent checking, not agent consensus, plus false-result mutants, interruption/restart, and bounded resource tests.
4. Preserve exact source/compiler/dependency identities, assumptions, derivations, immutable artifacts and measured time/memory/cost.
5. Benchmark against reproducible baselines; no unmeasured SOTA or nine-loop capability claims.
6. Keep RH research paused and RH scientific statuses unchanged.

## Coordination

MIND-Lab owns campaign admission; MIND owns language/compiler; MIND-CI owns execution verification; MIND-Parser owns extraction; MIND-Mem owns research continuity; NAESTRO owns orchestration. Keep solver and independent verifier distinct.
